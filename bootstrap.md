# Bootstrap Replacement List

This file records which Assignment 2 CSS rules were removed.

- Hand-written page grid: replaced by `container`, `row`, `col-12`, `col-md-6`, and `col-lg-4`.
- Hand-written navigation flexbox: replaced by `navbar`, `navbar-expand-md`, `navbar-nav`, and `collapse`.
- Hand-written button styling: replaced by `btn`, `btn-primary`, `btn-outline-primary`, `btn-lg`, and `disabled`.
- Hand-written table borders and spacing: replaced by `card`, responsive `col-*` classes, and a short `menu-list` helper.
- Hand-written form input widths and spacing: replaced by `form-control`, `form-select`, `form-check`, `row`, and `g-3`.
- Hand-written card spacing: replaced by `card`, `card-body`, `shadow-sm`, `mb-4`, `p-*`, and `g-*`.

My remaining CSS is only for Dostyk colours, fonts, image fitting, and one small mobile correction.
